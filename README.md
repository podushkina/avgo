# Безопаша — интерактивный антискам-тренажер

Обучающее веб-приложение для пользователей классифайда (Авито), которое помогает выявлять паттерны социальной инженерии и мошенничества в интерактивном формате до совершения рискованных действий.

## Сценарий взаимодействия

Пользователь проходит четыре последовательных этапа:

1. **Старт** — выбор роли (покупатель или продавец) и заполнение базового профиля (имя, возраст, пол).
2. **Обучение** — разбор типовых ситуаций в формате чата с выбором действий и мгновенной обратной связью с объяснением рисков.
3. **Экзамен** — симуляция реального диалога с мошенником на базе LLM. Модель динамически меняет тактики (увод в сторонние мессенджеры, фейковые ссылки на оплату, запрос кодов из SMS, психологическое давление срочностью). Критическая ошибка прерывает сессию.
4. **Результаты** — расчет итогового балла, детальный разбор совершенных действий и персональные рекомендации по безопасности.

```
Старт: выбор роли + профиль
        │
        ▼
Обучение: интерактивные сценарии
   ├─ выбор действия
   └─ моментальный разбор ошибок
        │
        ▼
Экзамен: диалог с ИИ-мошенником
   ├─ динамическая смена векторов атак
   └─ завершение при критической ошибке
        │
        ▼
Результаты: вердикт, разбор, рекомендации
```

## Архитектура и стек технологий

### Стек

- **Frontend:** React 19, TypeScript, Vite, MobX, Tailwind CSS, shadcn/ui, MSW (для моков API).
- **Backend:** Go (`net/http`), PostgreSQL (драйвер `pgx`, миграции `goose`), OpenAPI / Swagger UI.
- **AI / Инференс:** Ollama (`qwen2.5:7b`), OpenAI-совместимый API.
- **Инфраструктура:** Docker Compose, Nginx.

### Схема сервисов

```
                      Nginx :8080 (контейнер web)
        ┌────────────────────────┼────────────────────────┐
     /api/*                                               /
  (проксирование)                                    (React SPA)
        │
   api :8081 ──────────────► postgres :5433
   (Go-бэкенд)             (сессии, сценарии)
        │
        ▼
   ollama :11435 (контейнер) ИЛИ host.docker.internal:11434 (macOS Metal)
```

| Сервис | Порт на хосте | Назначение |
| :--- | :--- | :--- |
| `web` | `8080` | Nginx: раздача собранного React-приложения и проксирование API |
| `api` | `8081` (внутренний) | Go-бэкенд сервиса, автоматический запуск миграций базы данных |
| `postgres` | `127.0.0.1:5433` | База данных сессий, истории диалогов и аналитики |
| `ollama` | `127.0.0.1:11435` | Локальный инференс модели |
| `ollama-pull` | — | Одноразовый init-контейнер для автоматической загрузки весов модели |

## Работа с LLM

В режиме экзамена пайплайн обработки сообщений разделен на два независимых этапа на каждый шаг пользователя:

1. **Генерация реплики (Диалог):** LLM отыгрывает роль злоумышленника в соответствии с системным промптом и текущим вектором атаки. Ответ фильтруется санитайзером (замена ссылок на тестовые домены `.example`, удаление артефактов и зацикливаний). Текст пользователя напрямую в системный промпт не конкатенируется во избежание prompt injection.
2. **Классификация ответа:** отдельный вызов модели с передачей последнего действия пользователя. Модель возвращает строго типизированный JSON с оценкой уровня риска. На основе этого бэкенд принимает решение: продолжить сценарий, снизить скоринг или прервать экзамен с провалом.

> **Схема параметров ответа классификатора:**
> 
> ```json
> {
>    "risk_detected": true,
>    "attack_type": "phishing_link | offplatform | sms_code | prepayment",
>    "severity": "critical | warning | safe",
>    "explanation": "..."
> }
> ```

## Требования и быстрый запуск

### Требования
- Установленный Docker Desktop (с поддержкой Docker Compose).
- От 8 до 10 ГБ свободного дискового пространства.

### Запуск одной командой

```bash
git clone [https://github.com/dimortix/avgo.git](https://github.com/dimortix/avgo.git) && cd avgo
docker compose up -d --build
```

Приложение будет доступно по адресу: **http://localhost:8080**

*Примечание:* Первый запуск занимает 3–5 минут из-за загрузки образа Ollama и весов модели `qwen2.5:7b` (~4.7 ГБ). Контейнер `api` ожидает перехода `ollama` в статус `healthy` перед приемом трафика. Последующие запуски выполняются мгновенно.

Остановка контейнеров с удалением томов:
```bash
docker compose down -v
```

## Особенности запуска на разных ОС

### macOS
Docker Desktop на macOS выполняет контейнеры внутри виртуальной машины Linux без прямого доступа к Apple Silicon GPU (Metal), из-за чего инференс на CPU работает медленнее. Для использования GPU хоста:

1. Установите и запустите Ollama локально на хосте:
   ```bash
   brew install ollama
   ollama serve &
   ollama pull qwen2.5:7b
   ```
2. Запустите проект через специальный таргет (бэкенд переключится на `host.docker.internal:11434`):
   ```bash
   make up-host-llm
   ```

### Linux / Windows 
Поддерживается стандартный запуск через Compose, GPU пробрасывается при наличии настроенного `nvidia-container-toolkit`:
```bash
make up
```

## Режим работы без LLM 

Если запуск модели невозможен или требуется детерминированная демонстрация, предусмотрен fallback-режим:

1. Установите переменную в `.env`:
   ```env
   LLM_ENABLED=false
   ```
2. Перезапустите приложение:
   ```bash
   make up
   ```

В этом режиме реплики мошенника формируются по заранее описанному дереву сценариев, а оценка действий выполняется набором детерминированных правил на бэкенде.

## Команды управления (Makefile)

| Команда | Описание |
| :--- | :--- |
| `make up` | Сборка и фоновый запуск всех сервисов в Docker |
| `make up-host-llm` | Запуск с подключением к локальному инстансу Ollama на хосте (актуально для macOS) |
| `make down` | Остановка всех работающих контейнеров проекта |
| `make clean` | Остановка контейнеров и полное удаление Docker volumes (БД и кэш моделей) |
| `make smoke` | Запуск сквозных E2E-тестов API (35 проверок работоспособности) |
| `make test` | Запуск юнит- и интеграционных Go-тестов с флагом `-race` |
| `make lint` | Проверка кода линтером `golangci-lint` |
| `make help` | Вывод списка всех доступных команд |

*Для локальной разработки фронтенда без Docker:* `cd frontend && yarn install && yarn dev` (Vite настроен на проксирование `/api` на бэкенд).
