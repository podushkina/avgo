# Безопаша — интерактивный антискам-тренажёр

Кейс 5 «Антискам тренажёр». Обучающее веб-приложение, которое учит пользователя классифайда
распознавать мошенничество до того, как он совершит рискованное действие.

Путь пользователя — четыре шага:

1. **Старт** — выбор роли (покупатель или продавец) и заполнение короткого профиля: имя,
   возраст, пол.
2. **Обучение** — несколько реалистичных ситуаций в формате чата. На каждом шаге нужно выбрать
   действие и сразу получить разбор: верно ли это и почему.
3. **Экзамен** — непрерывный диалог с ИИ-мошенником. Модель пробует разные приёмы: ссылку на
   «безопасную оплату», код из СМС, данные карты, увод в мессенджер, давление срочностью.
   Заранее правильного ответа нет — навык приходится применять, а не вспоминать.
4. **Результаты** — вердикт экзамена, краткий разбор и персональные советы, что подтянуть
   в следующий раз.

Путь на схеме:

```
Старт: роль + профиль
        │
        ▼
Обучение: несколько ситуаций
   ├─ выбор действия
   └─ разбор сразу после ответа
        │
        ▼
Экзамен: диалог с ИИ-мошенником
   ├─ модель меняет приёмы
   └─ критическая ошибка обрывает сразу
        │
        ▼
Результаты: вердикт, разбор, советы
```

## Инструкция по запуску

Нужен установленный [Docker](https://docs.docker.com/get-docker/).

```bash
git clone https://github.com/dimortix/avgo.git && cd avgo
docker compose up -d --build
```

Приложение откроется на **http://localhost:8080**.

Дополнительно:

```bash
make up           # то же, что docker compose up -d --build
make down         # остановить
make clean        # остановить и удалить тома
make up-host-llm  # быстрее на macOS, если локально запущен ollama serve
make smoke        # сквозная проверка API
make test         # go-тесты
make lint         # golangci-lint
make help         # полный список команд
```

## Стек

**Фронтенд**

- React 19, TypeScript
- Vite
- React Router
- MobX
- Tailwind CSS, shadcn/ui
- MSW для локальных моков API
- Yarn

**Бэкенд**

- Go (`net/http`)
- PostgreSQL (драйвер pgx, миграции goose)
- Ollama — локальная LLM для экзамена (OpenAI-совместимый API)
- Docker Compose: `web` (nginx + собранный фронт), `api`, `postgres`, `ollama`

## Структура

**Фронтенд** (`frontend/src/`)

```

layouts/      BaseLayout, Header

**Бэкенд** (`services/api/`)

```
cmd/server/           точка входа
internal/
  httpapi/            хендлеры и роутинг
  domain/             статусы, вердикт, баллы
  storage/            PostgreSQL
  exam/               классификатор реплик

## Особенности реализации

**Авторизация.** Пользователь анонимный: после создания профиля бэкенд ставит httpOnly-куку
сессии. Фронт куку не читает и не шлёт в теле — она уходит с запросами автоматически.

**Как работает AI на экзамене.** Модель не выносит вердикт сама. На каждый ход два вызова:

1. **Диалог** — LLM играет мошенника и пишет следующую реплику. Системный промпт и служебные
   директивы хода задают роль и какой приём применить.
2. **Классификатор** — отдельный запрос только по последнему сообщению пользователя, ответ
   строго по JSON-схеме. По нему наш код решает: продолжать, снизить балл или сразу завершить
   экзамен с провалом.

Текст пользователя никогда не склеивается в системный промпт. Ответ модели проходит санитайзер
(вымышленные домены `.example`, обрезка мусора и зацикливаний). Если LLM недоступна —
детерминированные фолбэки, экзамен всё равно доходит до результата.

**Архитектура приложения:**

```
                      nginx :8080  (frontend/nginx.conf)
        ┌──────────────────┼──────────────────┐
     /api/*                                   /  (React SPA)
        │
   api-service :8081 ──► postgres :5432
        │
        ▼
   ollama :11434  (контейнер, поднимается той же командой)
    └─ опционально: host.docker.internal:11434 → нативная Ollama на macOS
```
