# Тренажер безопасности (хакатон Авито)

Стек:

- Yarn
- React
- TypeScript
- Vite
- CSS-in-JS с библиотекой Vanilla-extract в режиме Zero-runtime (генерирует CSS на стадии сборки)
- ESLint (разбит на пресеты) + Prettier

## Разработка и сборка

Для разработки запустить:

```sh
yarn dev
```

Сборка:

```sh
yarn build
```
